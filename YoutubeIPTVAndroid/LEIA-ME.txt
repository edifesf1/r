YOUTUBE IPTV PARA ANDROID TV / TV BOX

O app consulta este arquivo ao iniciar:
https://raw.githubusercontent.com/edifesf1/r/refs/heads/main/link.txt

O endereço atualmente informado no TXT será aberto no WebView em tela cheia.

COMO GERAR O APK GRATUITAMENTE PELO GITHUB ACTIONS
1. Extraia este ZIP.
2. Crie um repositório GitHub novo (ou use um repositório separado para não misturar com o site).
3. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
4. Abra a aba Actions no GitHub e selecione "Build Android APK".
5. Clique em "Run workflow" caso a execução não comece automaticamente.
6. Ao terminar, abra a execução concluída e baixe o artefato "Youtube-IPTV-APK".
7. Extraia o artefato ZIP: dentro estará app-debug.apk.
8. Copie o APK para a TV Box e instale. Talvez seja necessário permitir instalação de fontes desconhecidas.

OBSERVAÇÕES
- Este ambiente não tem Android SDK/Gradle instalado, portanto o APK binário não foi compilado aqui. O projeto inclui uma ação GitHub para gerar o APK.
- A primeira abertura exige internet para consultar link.txt e carregar o site.
- O app usa WebView do Android. A reprodução do YouTube pode depender das regras do YouTube, da versão do Android System WebView e do suporte do dispositivo.
